Usar cornisa desde un CDN

Aviso: el paquete cornisa todavía no está publicado. Las URLs de CDN de estos ejemplos (jsDelivr / unpkg) darán 404 hasta que se publique la versión 0.2.0-alpha.0. Mientras tanto, cada ejemplo usa automáticamente la copia local de ../../dist/ y lo indica en pantalla.

  1. Script clásico: <script src> + window.Cornisa, con SRI.
  2. Módulo ESM: import { createIsland } from "https://…/cornisa.esm.min.js".
  3. Import map: import { createIsland } from "cornisa".
  4. Casos de uso completos: progreso, promise, temporizador, deshacer, cola, atajo, etiquetas en español y tokens.

Consola: mientras no esté publicado verás «Refused to apply style / execute script… MIME type ('text/plain')» y un 404. Es la respuesta del CDN («esa versión no existe»), no un fallo de los ejemplos.

Doble clic (file://): funciona, pero los ejemplos 02 y 03 usan el script clásico porque el navegador no carga módulos ES desde file://. Para probarlos como módulos: python3 -m http.server en esta carpeta.

Archivos que sirve el CDN

dist/cornisa.iife.min.js   → <script> clásico (window.Cornisa)
dist/cornisa.esm.min.js    → <script type="module"> / import map
dist/cornisa.min.css       → estilos neutros (tokens --cornisa-*)
dist/sri.json              → hashes de integridad (SRI) de esta versión

Los archivos de dist/ están transpilados para Chrome/Edge ≥ 84, Firefox ≥ 69 y Safari/iOS ≥ 14 (suelo declarado, no probado en esas versiones).
