Layout adaptativo automático

Prototipo estructural de Kiwi. Un contenedor y contenido: el motor mide etiquetas, usa pistas del control y conserva el orden. Nombres de API pendientes de Lima.

Laboratorio
Contenido externo sin perfil: conserva un respaldo seguro, sin inferir su significado.

Ver cálculo, fórmula y pistas utilizadas

Para cada fila: suma de mínimos más separaciones debe caber. Se minimiza filas + 24 × pérdida relativa cuadrática respecto al ancho preferido. Después se reparte el espacio por pesos, respetando máximos. El coeficiente 24 es una elección experimental, no un estándar.

Cómo lo usaría el desarrollador (propuesta)
<GAdaptiveLayout>
  <GInput label="Calle" />
  <GNumberField label="Exterior" :min="0" :max="9" :precision="0" />
  <GNumberField label="Interior" :min="0" :max="9" :precision="0" />
</GAdaptiveLayout>

No se necesita declarar columnas ni longitud esperada para estos números: el rango acotado aporta una pista. Texto libre usa un perfil de respaldo. El rango no demuestra cuánto escribe una persona.
